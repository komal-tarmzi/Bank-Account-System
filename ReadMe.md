# 🏦 C# Bank Account System

A simple and beginner-friendly **console-based Bank Account System** developed using **C#**. This project simulates basic banking operations such as creating an account, depositing money, withdrawing money, checking the account balance, and displaying account information.

The project focuses on practicing fundamental **C# programming and Object-Oriented Programming (OOP)** concepts.

---
## 📌 Features

* 👤 Create a bank account
* 💰 Deposit money
* 💸 Withdraw money
* 💵 Check account balance
* 📋 Display account information
* ⚠️ Prevent withdrawals when the balance is insufficient
* 🖥️ Interactive console-based menu
* 🔄 Perform multiple operations until the user exits

## 📂 Project Structure

```text
CSharp-Bank-Account-System/
│
├── Program.cs
├── BankAccount.cs
└── README.md
```

### `Program.cs`

Contains the main application logic and interactive console menu.

It handles:

* User choices
* Deposits
* Withdrawals
* Balance checking
* Account information display

### `BankAccount.cs`

Contains the `BankAccount` class that represents a bank account.

The class manages:

* Account holder name
* Account number
* Account balance
* Deposit operations
* Withdrawal operations
* Balance information

## ▶️ How to Run

### Using Visual Studio

1. Clone this repository.
2. Open the project in **Visual Studio**.
3. Open the `.csproj` file if required.
4. Build the project.
5. Run the application using **Ctrl + F5** or the **Start** button.

## 🖥️ Example

When the program starts, the user is presented with a menu:

```text
===== BANK ACCOUNT SYSTEM =====
1. Create Account
2. Deposit Money
3. Withdraw Money

5. Account Information
6. Exit

Choose an option:
```

```text

```

### Withdrawal Example

```text
Enter amount to withdraw: 1500

Withdrawal successful!
Current Balance: 3500.00
```

```text

```
